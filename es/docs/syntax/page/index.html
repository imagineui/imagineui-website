Página

Uso

Empieza cada escena con la palabra clave Página y un nombre:

Página "Registrarse"
Bloque "Navegación principal"
    ...
Bloque "Datos personales"
    ...
Bloque "Pie de página"

El nombre de la página no va a aparecer en la maqueta procesada y simplemente está para que te acuerdes mejor de qué va cada escena.

El orden de palabras y la capitalización no tienen importancia:

página "Registrarse"
...
