Документация ImagineUI

ImagineUI преобразует текстовые описания интерфейсов в визуальные мокапы:

Page: Authorization
Main block: Login
    Image logo
    Header
    Field: "e-mail or phone number"
    Password field
    "Log in" button
Service block
    One row
    "Sign up" button
    "Reset password" button
    "2020 @ImagineUI"
Help block
    Two columns
    List of topics
        consists of
            Header
            <Link to blog post>
